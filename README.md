# Практическая работа 3. Работа с CSV и XML файлами

Консольное приложение для работы со справочниками городов в форматах CSV и XML.

## Описание
Приложение считывает путь к файлу, автоматически определяет его формат (.csv или .xml), парсит данные и выводит сводную статистику:
1. Дублирующиеся записи с количеством повторений.
2. Количество 1, 2, 3, 4 и 5-этажных зданий в каждом городе.
3. Время обработки файла в миллисекундах.

## Архитектура и ООП
Проект спроектирован согласно принципам объектно-ориентированного программирования:
* **Модель данных:** `Address` (с переопределенными `equals` и `hashCode` для поиска дубликатов).
* **Общий контракт:** Интерфейс `AddressParser`, который реализуют `CsvAddressParser` и `XmlAddressParser`.
* **Статистика:** `StatisticsCalculator` (используется `HashMap` и `TreeMap` для быстрой обработки).
* **Интерфейс:** `ConsoleUI` (взаимодействие с пользователем).
* **Точка входа:** `Main`.

## Технологии
* Java 11+
* Стандартные библиотеки Java (для CSV используется `BufferedReader`, для XML — `DOM`).

## Как запустить
1. Склонируйте репозиторий.
2. Откройте проект в IDE.
3. Запустите класс `Main.java`.
4. Введите путь к файлу `.csv` или `.xml` (например, `files/address.csv`).
5. Для выхода введите команду `exit`.
